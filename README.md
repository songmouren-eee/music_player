# 音乐播放器

一款简洁高效的在线音乐播放器，让听歌回归纯粹。

## 功能特性

- **海量音乐搜索**：输入歌名或歌手，即可快速检索到你想听的歌曲
- **在线流畅播放**：支持在线播放，无需下载，即点即听
- **简洁界面设计**：专注于核心播放体验，操作直观，上手即用

## 优势亮点

- **无广告打扰**：全程没有任何广告插播，还给你干净的听歌环境
- **无 VIP 限制**：所有功能完全开放，不存在会员专享或付费解锁
- **完全免费**：不收取任何费用，下载即用，永久免费

## 注意事项

本应用的音乐数据来源于第三方公开接口，因此可能存在以下情况：

- 部分歌曲因接口变动而暂时无法播放
- 搜索结果或播放链接偶尔出现失效
- 服务稳定性依赖第三方源，可能出现波动

如遇无法播放的情况，可尝试重新搜索或稍后再试。
